# История разработки

Часть [[Claude VM GUI]].

## 2026-10-18

- Согласованы подход (терминал в оболочке claude.ai), стек (Electron) и макет из 5 экранов.
- Написана спецификация, заведён репозиторий. Кода пока нет. Подробности — [[Дизайн и решения]].
- Написан план реализации из 13 задач: `docs/superpowers/plans/2026-10-18-claude-vm-gui.md`.
- Task 1: каркас Electron + React, безопасные настройки окна, git-хук против утечки адреса ВМ.
- Task 2: чистые функции и их тесты (58 тестов), фикстура ответа `initialize`.
- Task 3: конфигурация подключения и мост IPC между интерфейсом и главным процессом.
- Task 4: проверка ping (предупреждение) и TCP (обязательна) перед подключением.
- Task 5: SSH-соединение, проверка ключа хоста по known_hosts, автопереподключение; тестовый ключ только для localhost.
- Task 6: сервисы tmux и терминала; команды tmux адресуют сессию по точному имени, чтобы не задеть похожие.
- Task 7: подсказки команд, моделей, файлов и папок; загрузка картинок по SFTP.
- Task 8: экран подключения, настройки, проверка ключа нового сервера; сервисы подключены к интерфейсу.
- Task 9: главное окно — список сессий, шапка, терминал xterm.js, создание и завершение сессий.
- Task 10: поле ввода в стиле claude.ai — подсказки команд и файлов, вставка картинок, выбор модели и effort.
- Task 11: сквозной E2E-сценарий с обрывом связи; после переподключения «Подключено» показывается только когда терминал снова в сессии. Скриншоты в `docs/screenshots/`.
- Task 12: сборка под Windows (NSIS + portable), CI на windows-latest, README со скриншотами, лицензия MIT.
- Task 13: проверка с настоящим claude (подсказки скиллов, /model, /effort, картинка); добавлена защита от отправки в открытое меню Claude Code.
- Финальное ревью: исправлены выполнение текста в bash без claude, таймаут окна ключа сервера, подмена типа ключа, кириллица в подсказках файлов, двойная отправка, точка в имени сессии, медленное обнаружение обрыва, гонка при открытии сессии, запуск хуков проекта при запросе подсказок.
- Копирование и вставка в терминале: Ctrl+C при выделении, Ctrl+Shift+C/V, правая кнопка мыши.
- Версия 0.1.1: релиз со сборкой под Windows через CI (тег v0.1.1).
- Буфер обмена: скопированное в Claude Code и tmux (`tmux load-buffer -w` → OSC 52) попадает в буфер Windows; выделение с Shift больше не сбрасывается, когда Claude Code отслеживает все движения мыши; чтение и запись буфера через главный процесс.
- Версия 0.1.2: буфер обмена через OSC 52 и выделение с Shift (тег v0.1.2).

## 2026-10-19

- Начата версия 0.2: отправка одним Enter, вход по паролю, панель «Сервер», лента переписки вместо терминала, группы и закрепление сессий. Спецификация: `docs/superpowers/specs/2026-10-19-claude-vm-gui-v0.2-design.md`.
- Проверка на настоящем claude: второй Enter нужен, когда Enter приходит в одном куске с концом вставки (склейка пакетов по сети) — Claude Code его теряет. Написан план 0.2 из 10 задач: `docs/superpowers/plans/2026-10-19-claude-vm-gui-v0.2.md`.
- 0.2, Task 1: фейковый API и снимки экранов настоящего claude; разбор поля ввода (серая подсказка и серый «❯» во время работы не считаются текстом), меню (с номерами и без, переносы, линия внутри AskUserQuestion), статуса.
- 0.2, Task 2: отправка одним Enter — фейковый claude воспроизвёл потерю Enter, исправление проверено на нём и на настоящем claude (картинка, 40 строк).
- 0.2, Task 3: вход по паролю (safeStorage, keyboard-interactive), проверено на тестовом SSH-сервере внутри тестов; поле пароля в настройках.
- 0.2, Task 4: модель раскладки сайдбара (порядок, закрепление, группы, страницы) и её хранение для каждой ВМ.
- 0.2, Task 5: сайдбар — закрепление (булавка), группы со сворачиванием, перетаскивание, меню по ПКМ, страницы с пейджером; E2E на отдельном сервере tmux.
- 0.2, Task 6: разбор журнала Claude Code и слежение за ним по SSH.
- 0.2, Task 7: наблюдение за сессией (экран, меню, занятость, связка с журналом), клавиши меню из белого списка; исправлено: если после Enter сразу появляется меню, отправка не жмёт Enter повторно.
- 0.2, Task 8: лента переписки вместо терминала, карточки меню, переключатель «Лента | Терминал», ссылки в браузере; claude распознаётся и когда он сам — процесс панели.
- 0.2, Task 9: панель «Сервер» — CPU с графиком, память, диски, сеть, процессы с именами сессий claude, сведения о системе.
- 0.2, проверка с настоящим claude через фейковый API: доверие папке, картинка, Bash с разрешением, AskUserQuestion стрелками, /model, «Остановить». Исправлено: карточка меню всплывает поверх ленты (раньше терминал под лентой ужимался, и Claude Code обрезал меню); журнал новой сессии, которого ещё нет, — это пустая лента, а не ошибка; код в карточке — по пунктирам «╌».
- 0.2, Task 10: скриншоты (лента, карточка меню, панель «Сервер», группы), README, версия 0.2.0; проверка ввода после переподключения в E2E не зависит от переносов строк.
- 0.2, финальное ревью (отдельный агент): исправлены отправка Enter в открывшееся меню разрешения, вход по паролю при выключенном ssh-agent (и утечка соединения), затирание раскладки сайдбара при запуске, ложная карточка меню (общий детектор меню), порядок клавиш карточки, строки журнала длиннее окна чтения и квадратичный перебор регулярки на них, пустая лента при ненайденной сессии claude (теперь терминал; поиск по всем потомкам панели), повтор Enter без снимков экрана.
- Версия 0.2.0: релиз со сборкой под Windows через CI (тег v0.2.0). Первая сборка упала: на Windows-checkout фикстуры получили CRLF — добавлен `.gitattributes` (`eol=lf` для `tests/fixtures`).
- 0.2.1: ответ Claude появляется посимвольно, звёздочка при работе, отправленное сообщение видно сразу (темнее до доставки), «Новая сессия…» в меню группы, меню пустого места сайдбара (сессия, группа), таблица процессов с рамками, «Завершить сессию» цвета опасного действия.
- 0.2.1, ревью: временный пузырь совпадает с «! cmd» в журнале, одна запись не снимает второй одинаковый пузырь, пока Claude работает — пузырь не исчезает (сообщение в очереди), в тёмной теме отправляемый пузырь заметен.
- Версия 0.2.1: релиз (тег v0.2.1).
- 0.2.2 (отложенные мелочи 0.2 и 0.2.1): перетаскивание переживает перелистывание страниц (раньше Chromium обрывал его, и линия вставки оставалась), новая сессия в свёрнутую группу разворачивает её и попадает в группу даже при сбое обновления списка, меню пустого места с клавиатуры, ПКМ по фону диалога не открывает меню списка, действия параллельных субагентов — у своих Task, `keyBytes` только для строк, ссылки через `new URL`, склонение «ядер».
- 0.2.2, лента: своё сообщение прокручивает вниз, колесо вверх во время печати не возвращает вниз, ответы длиннее 10 000 символов — сразу, `/clear` сбрасывает «печать», дописанный ответ допечатывается, фокус в поле ввода после карточки меню и когда терминал прячется под ленту.
- 0.2.2, главный процесс: Enter не считается принятым, если поле лишь изменилось (поздняя отрисовка картинки) — повтор; потерянная вставка — ошибка вместо «отправлено»; лента не запускается по устаревшему `open`; «нет данных» на панели «Сервер» во время переподключения и частые замеры после нового подключения; нерасшифрованный пароль объясняется в настройках и в ошибке входа. Запасной id записи журнала совпасть не может (проверено тестом) — ложная находка ревью 0.2.
- 0.2.2, ревью (отдельный агент): «вставка потерялась» больше не срабатывает, когда поле просто перестало распознаваться (ломало отправку `! cmd`), медленная вставка получает ещё один снимок, а ошибка советует проверить поле; клавиши прокрутки после щелчка по ленте; нерасшифрованный пароль удаляется пустым полем.
- Версия 0.2.2: релиз (тег v0.2.2).

## 2026-10-22

- Начата версия 0.3 (вместе с Android 0.2): баннер обновлений, строка сессии выше, без сводки сжатия в ленте, вставки без тегов `pasted_content`, меню в ленте радиокнопками и чекбоксами, вложения любых файлов и их содержимое в ленте, размер tmux по активному устройству, поле ввода очищается сразу, без поля в режиме «Терминал». Спецификация: `docs/superpowers/specs/2026-10-22-claude-vm-v0.3-design.md`, план: `docs/superpowers/plans/2026-10-22-claude-vm-v0.3.md`.
- 0.3: огромное сообщение в ленте — сводка сжатия контекста (`isCompactSummary`), а не кэш; висевший внизу пузырь — Claude Code пишет многострочную вставку в журнал обёрнутой в `<pasted_content id=…>`, и пузырь не узнавал своё сообщение.
- 0.3: хвосты букв в строке сессии обрезались из-за `line-height: normal` (у Segoe UI выше) — строка 56 px, высота строк текста явная.
- 0.3: окно tmux при `window-size latest` берёт размер клиента с последней активностью; «фокус получен» (`ESC [ I`) делает клиента последним, а в программу панели не попадает (проверено опытом с двумя клиентами) — приложение шлёт его при фокусе окна.
- 0.3: картинки Claude Code заменяет на `[Image #N]` и данные в журнале (путь пропадает) — в ленте они показываются из журнала; остальные файлы читаются с ВМ (`upload.read`, только внутри папки загрузок).
- 0.3: снимки меню Claude Code 2.1.308 (множественный выбор «[ ]/[✔]», «Submit», вкладки вопросов, «Review your answers» без подсказки, свой ответ, ось effort); сценарий снимков и тест наблюдения — на своём сервере tmux (к общему был подключён телефон в 43 колонки).
- 0.3, попутно: из Android-форка перенесены встроенные команды Claude Code 2.1.306+ в подсказках и `~/.local/bin` в PATH для `claude`; отправка сразу после выбора сессии ждёт подключения терминала (раньше «Сессия не открыта»).
- 0.3, ревью (отдельный агент): ввод, клавиши меню и свой ответ знают свою сессию — при быстром переключении не уходят в другую; итоги меню без якоря — вверху, с незагруженным — скрыты; Esc и Ctrl+C в терминале — «отменено»; номера вариантов в карточке.
- Версия 0.3.0: релиз (тег v0.3.0).

## 2026-10-24

- Начата 0.4 (вместе с Android 0.2): без служебных `<task-notification>` в ленте, effort ползунком, расход Claude внизу сайдбара — лимиты подписки «5 часов» и «Неделя» (тот же сервис, что у `/usage`) и токены за сегодня по журналам всех сессий.
- 0.4: граница суток для токенов — `date -u -d "<дата> 00:00"` понимал полночь как UTC и терял ответы до 02:00 по CEST; интеграционный тест поймал.
- 0.4, ревью (отдельный агент): токен подписки — строго из `claudeAiOauth` (жадный sed брал последний `accessToken` в файле — токен MCP-сервера ушёл бы на api.anthropic.com), заголовок — here-doc вместо printf; сбой сервиса лимитов или оборванный вывод не стирают показанные полоски («нет подписки» — отдельный маркер); ползунок: отпускание на том же месте при неизвестном уровне тоже выбирает его, стрелки — одна команда после паузы; сбой `tmux ls` при подключении больше не стирает раскладку.
- Версия 0.4.0: релиз (тег v0.4.0).
- Начата 0.5 (вместе с Android 0.3): контекст сессии в шапке — «занято» по журналу, разбивка из вывода `/context` (Claude Code 2.1.310 пишет его в журнал целиком, с ANSI-цветами), кнопка «Сжать сессию» (`/compact` с пожеланиями). Спецификация `docs/superpowers/specs/2026-10-24-context-panel-design.md`.
- 0.5: формат токенов — «832.3k», «1M» (решение пользователя), «Расход» тоже; пометка «Разбивка на HH:MM» — по тому, пришёл ли замер в это открытие панели (сравнение часов журнала и клиента давало нестабильный тест).
- 0.5, ревью (отдельный агент): `/context`, набранный в поле ввода, не висит пузырём; вывод после команды `/context` скрыт при любом формате и типе записи; модель замера — из вывода `/context` (после `/model` без ответа окно запоминалось на старую модель); после `/compact` настоящий Claude Code не пишет ответа с usage — «занято» берётся из замера, если он новее; полоска по категориям — только когда разбивка совпадает с числом; в «занято» входят и выходные токены ответа.
- Версия 0.5.0: релиз (тег v0.5.0).
- 0.5.1: разбивка `/context` — только по кнопке «Обновить разбивку» (замечено в работе: вывод `/context` остаётся в контексте сессии, ~2k токенов на каждое открытие панели; решение пользователя).
- Версия 0.5.1: релиз (тег v0.5.1).
- 0.6 (вместе с Android 0.4), спецификация `docs/superpowers/specs/2026-10-26-outbox-menus-effort-design.md`: файлы Claude для пользователя — папка «для вас» `~/.cache/claude-vm-gui/outbox` вместо публикации на claude.ai (правило в `/root/.claude/CLAUDE.md`), карточки под ответом (картинка, текст, «Открыть в браузере», «Сохранить»); меню собирают выбор локально и отправляют одной пачкой клавиш (раньше каждое нажатие ждало перерисовки экрана; проверено на настоящем Claude Code 2.1.310 — пачка принимается даже одним куском); effort — кнопкой с уровнем и панелью с делениями. Попутно: строка файла без раскрытия была шире карточки (`box-sizing`).
- Версия 0.6.0.
