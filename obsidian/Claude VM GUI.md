# Claude VM GUI

Windows-приложение для работы с Claude Code, который запущен на ВМ (Ubuntu) в tmux. Заменяет ручной сценарий «cmd → ssh → tmux attach/new → claude → tmux kill-session» кнопками и показывает переписку в интерфейсе в стиле claude.ai (версия 0.5).

## Как пользоваться

1. Запустить приложение — оно проверяет ping и TCP:22, затем подключается по SSH-ключу или паролю.
2. Слева выбрать tmux-сессию или создать новую (имя + рабочая папка, claude запускается сам). Сессии можно перетаскивать, закреплять и собирать в группы (ПКМ).
3. Пока работает claude, вместо терминала — лента переписки; меню Claude Code — карточкой в ленте (радиокнопки, чекбоксы). Писать в поле ввода внизу: подсказки по `/` и `@`, любые файлы через 📎, Ctrl+V или перетаскивание (в ленте — картинка целиком, текст раскрывается), смена модели и effort (ползунком). Новая версия на GitHub — баннер вверху.
4. Внизу слева — расход Claude: лимиты подписки «5 часов» и «Неделя» и токены за сегодня; «Сервер» — CPU, память, диски, сеть, процессы ВМ.
5. В шапке сессии — «Контекст N %»: панель с разбивкой (как `/context`), «Токенов до автосжатия» и «Сжать сессию» (`/compact` с пожеланиями).
6. Кнопка «Завершить сессию» — `tmux kill-session`.
