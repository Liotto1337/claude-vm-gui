# Claude VM GUI

Windows-приложение для работы с Claude Code, который запущен на ВМ (Ubuntu) в tmux. Заменяет ручной сценарий «cmd → ssh → tmux attach/new → claude → tmux kill-session» кнопками и оборачивает терминал в интерфейс в стиле claude.ai.

## Как пользоваться

1. Запустить приложение — оно проверяет ping и TCP:22, затем подключается по SSH-ключу.
2. Слева выбрать tmux-сессию или создать новую (имя + рабочая папка, claude запускается сам).
3. Писать в поле ввода внизу: подсказки по `/` и `@`, картинки через Ctrl+V, смена модели и effort.
4. Кнопка «Завершить сессию» — `tmux kill-session`.
