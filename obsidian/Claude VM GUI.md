# Claude VM GUI

Windows-приложение для работы с Claude Code, который запущен на ВМ (Ubuntu) в tmux. Заменяет ручной сценарий «cmd → ssh → tmux attach/new → claude → tmux kill-session» кнопками и показывает переписку в интерфейсе в стиле claude.ai (версия 0.2).

## Как пользоваться

1. Запустить приложение — оно проверяет ping и TCP:22, затем подключается по SSH-ключу или паролю.
2. Слева выбрать tmux-сессию или создать новую (имя + рабочая папка, claude запускается сам). Сессии можно перетаскивать, закреплять и собирать в группы (ПКМ).
3. Пока работает claude, вместо терминала — лента переписки; меню Claude Code — карточкой. Писать в поле ввода внизу: подсказки по `/` и `@`, картинки через Ctrl+V, смена модели и effort.
4. «Сервер» внизу слева — CPU, память, диски, сеть, процессы ВМ.
5. Кнопка «Завершить сессию» — `tmux kill-session`.
