# Структура кода

Часть [[Claude VM GUI]].

| Путь | Назначение |
|---|---|
| `src/main/index.ts` | Окно, настройки безопасности (contextIsolation, sandbox, CSP), запрет навигации |
| `src/main/config.ts` | `loadConfig` (config.json → vm.config.json при разработке; пароль не возвращает, только `hasPassword`, а если не расшифровался — `passwordUnreadable`), `loadPassword`, `saveConfig` с проверкой и шифрованием пароля (`SecretBox`) |
| `src/main/preflight.ts` | `runPing` (системный ping, cp866 на Windows), `checkTcp`, `runPreflight` |
| `src/main/ssh.ts` | `SshConnection`: ключ → ssh-agent → пароль → keyboard-interactive (методы, которых сервер не предлагает, не пробуются), проверка known_hosts, exec/PTY/SFTP, автопереподключение |
| `src/main/tmux.ts` | `TmuxService`: list/create/kill/startClaude по точному имени (`=имя`), опрос списка |
| `src/main/terminal.ts` | `TerminalService`: отправка, клавиши, свой ответ, /model и /effort получают имя сессии, из которой пришли (`target`): ждут идущего подключения (`opening`), а если тем временем выбрали другую сессию или сменился канал — `NO_SESSION`, ничего не пишется; `activate()` — «фокус получен» (`ESC [ I`) в канал attach, не чаще раза в 500 мс: при `window-size latest` окно tmux принимает размер этого устройства (вызывается при фокусе, разворачивании и показе окна; подключение к сессии само делает клиента последним); `tmux attach` с PTY, send (bracketed paste, Enter — когда поле ввода устоялось, с проверкой, что сообщение ушло — поле опустело или пропало, а не просто изменилось (поздняя отрисовка вставки), — и одним повтором; поле пустое до Enter и после ещё одной паузы — вставка потерялась, ошибка без Enter; поле перестало распознаваться, например bash-режим «!» — Enter вслепую, как раньше), /model, /effort, причина выхода; не пишет в терминал, если открыто меню Claude Code («Esc to cancel») |

| `src/main/upload.ts` | `UploadService.read` — начало файла из папки загрузок или outbox для ленты (после `realpath` только внутри папки: «..» и ссылки наружу — `BAD_PATH`, удалённый — `NOT_FOUND`); `UploadService.file`: любые файлы до 50 МБ по SFTP в `~/.cache/claude-vm-gui/uploads/` (права 0600), прогресс, чистка старше 7 дней (и outbox); `download` — файл outbox (`~/.cache/claude-vm-gui/outbox`) потоком в файл на компьютере через `.part`, обрыв или недобор байт — частичный файл удаляется |
| `src/shared/upload-name.ts` | Имя на ВМ `ГГГГММДД-ЧЧММСС-xxxxxx-<исходное имя>` (`remoteName`: всё, кроме букв, цифр, `.-_`, → `_`, до 80 символов с расширением), `displayName`, `isImageName`, `MAX_FILE_BYTES`; `outboxPaths` — пути к файлам папки «для вас» (`~/.cache/claude-vm-gui/outbox`) в тексте ответа Claude (кавычки, скобки, markdown-ссылка, пунктуация в конце) |
| `src/main/controller.ts` | `AppController`: подключение (preflight → SSH → tmux), запрос ключа хоста, все обработчики `window.api`; лента открытой сессии (`chat:*`) — наблюдение за экраном и журналом (только для текущей сессии: устаревший `open` ленту не запускает), перезапуск после переподключения; не принятый вход с нерасшифрованным паролем — с подсказкой ввести его заново |
| `src/main/ipc.ts` | `IpcHub`: каналы «группа:метод», события «группа:событие», заглушки `NOT_CONNECTED`; буфер обмена (`clipboard:read`/`clipboard:write`) через `clipboard` Electron |

| `src/renderer/api.ts` | Типизированный `api` для компонентов |
| `src/renderer/state.ts` | Хранилище состояния (`useAppState`), подключение, тема, раскладка сайдбара (`updateLayout`, сверка со списком tmux); контекст сессии в `chat[сессия].context` |
