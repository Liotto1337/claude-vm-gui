# Структура кода

Часть [[Claude VM GUI]].

| Путь | Назначение |
|---|---|
| `src/main/index.ts` | Окно, настройки безопасности (contextIsolation, sandbox, CSP), запрет навигации |
| `src/main/config.ts` | `loadConfig` (config.json → vm.config.json при разработке; пароль не возвращает, только `hasPassword`, а если не расшифровался — `passwordUnreadable`), `loadPassword`, `saveConfig` с проверкой и шифрованием пароля (`SecretBox`) |
| `src/main/preflight.ts` | `runPing` (системный ping, cp866 на Windows), `checkTcp`, `runPreflight` |
| `src/main/ssh.ts` | `SshConnection`: ключ → ssh-agent → пароль → keyboard-interactive (методы, которых сервер не предлагает, не пробуются), проверка known_hosts, exec/PTY/SFTP, автопереподключение |
| `src/main/tmux.ts` | `TmuxService`: list/create/kill/startClaude по точному имени (`=имя`), опрос списка |
| `src/main/terminal.ts` | `TerminalService`: `tmux attach` с PTY, send (bracketed paste, Enter — когда поле ввода устоялось, с проверкой, что сообщение ушло — поле опустело или пропало, а не просто изменилось (поздняя отрисовка вставки), — и одним повтором; поле пустое до Enter и после ещё одной паузы — вставка потерялась, ошибка без Enter; поле перестало распознаваться, например bash-режим «!» — Enter вслепую, как раньше), /model, /effort, причина выхода; не пишет в терминал, если открыто меню Claude Code («Esc to cancel») |
| `src/main/hints.ts` | `HintsService`: команды и модели через `initialize` (кэш), файлы через git ls-files/find, папки по мере ввода |
| `src/main/upload.ts` | `UploadService`: картинки по SFTP в `~/.cache/claude-vm-gui/uploads/`, прогресс, чистка старше 7 дней |
| `src/main/controller.ts` | `AppController`: подключение (preflight → SSH → tmux), запрос ключа хоста, все обработчики `window.api`; лента открытой сессии (`chat:*`) — наблюдение за экраном и журналом (только для текущей сессии: устаревший `open` ленту не запускает), перезапуск после переподключения; не принятый вход с нерасшифрованным паролем — с подсказкой ввести его заново |
| `src/main/ipc.ts` | `IpcHub`: каналы «группа:метод», события «группа:событие», заглушки `NOT_CONNECTED`; буфер обмена (`clipboard:read`/`clipboard:write`) через `clipboard` Electron |
| `src/preload/index.ts` | Мост `window.api` через contextBridge, реализует `Api` |
| `src/renderer/api.ts` | Типизированный `api` для компонентов |
| `src/renderer/state.ts` | Хранилище состояния (`useAppState`), подключение, тема, раскладка сайдбара (`updateLayout`, сверка со списком tmux) |
| `src/renderer/components/ConnectScreen.tsx` | Шаги ping → TCP → SSH → tmux, «Повторить», «Настройки» |
| `src/renderer/components/SettingsDialog.tsx` | Адрес, порт, пользователь, ключ, пароль («Пароль сохранён» / «Изменить» / «Удалить»; не расшифровался — просьба ввести заново, пустое поле его удаляет: `settings-password.ts` `passwordToSave`), тема |
| `src/renderer/components/HostKeyDialog.tsx` | «Новый сервер»: отпечаток SHA256, «Доверять» / «Отмена» |
| `src/renderer/components/MainView.tsx` | Главное окно: список сессий, шапка, лента или терминал (`viewMode`), плашка обрыва связи и «не удалось прочитать переписку» |
| `src/renderer/chat-anim.ts` | «Печать» ответа (`typingSpeed`, `revealCount`: от 120 символов/с, не дольше 1,5 с) и временные пузыри отправленных сообщений (`claimPending`); `nextTyping` — какие ответы печатать (только новые из живого журнала, не длиннее `TYPE_MAX_CHARS` = 10 000 символов; `/clear` сбрасывает) |
| `src/renderer/components/Spinner.tsx`, `TypedMarkdown.tsx` | Звёздочка Claude Code (`· ✢ ✳ ✶ ✻ ✽`), посимвольное появление ответа (дописанный во время печати текст допечатывается); при «уменьшить анимацию» — без анимации |
| `src/renderer/view-mode.ts` | `viewMode` (лента или терминал), `mergeItems` (события журнала → список ленты) |
| `src/renderer/components/ChatView.tsx`, `ChatItemView.tsx`, `Markdown.tsx` | Лента: сообщения, ответы в markdown (react-markdown + remark-gfm, без сырого HTML), инструменты с раскрытием, «Показать раньше», автопрокрутка (своё сообщение — всегда вниз; колесо или ↑ PageUp Home вверх отключают слежение до самого низа; щелчок по ленте отдаёт ей фокус, чтобы клавиши ловились), строка статуса |
| `src/renderer/components/ServerPanel.tsx`, `Sparkline.tsx` | Панель «Сервер»: процессор (график), память и swap, диски (от 80 % — глиняный, от 90 % — красный), сеть, топ процессов, сведения; график — свой SVG |
| `src/renderer/components/MenuCard.tsx` | Меню Claude Code карточкой: ↑↓←→ Enter Esc Tab цифры уходят в claude, клик по варианту; после закрытия фокус возвращается в поле ввода (`Composer`) |
| `src/renderer/components/Sidebar.tsx` | Строка подключения, «Новая сессия», список сессий, настройки |
| `src/renderer/components/SessionList.tsx` | Сессии и группы по страницам (`ROW_HEIGHTS`), закрепление, перетаскивание (HTML5 DnD, линия вставки, перелистывание при наведении на стрелку; строки всех страниц в DOM, чужие скрыты — иначе перетаскивание обрывается при перелистывании), меню по ПКМ и Shift+F10 (в том числе «Новая сессия…» в группе и меню пустого места: новая сессия, новая группа; список достижим Tab-ом), Alt+↑/↓ |
| `src/renderer/components/ContextMenu.tsx`, `GroupNameDialog.tsx` | Меню с подменю и управлением с клавиатуры (ключи пунктов с индексом: имена групп повторяются); название группы |
| `src/renderer/components/SessionHeader.tsx` | Имя, папка, переключатель «Лента | Терминал» (когда запущен claude), «Завершить сессию» с подтверждением |
| `src/renderer/components/TerminalView.tsx` | xterm.js + fit-addon, копирование и вставка (Ctrl+C при выделении, Ctrl+Shift+C/V, правая кнопка), OSC 52 из tmux и Claude Code в буфер Windows, выделение с Shift не сбрасывается от движения мыши, «Сессия завершена» / «Отключено от сессии»; спрятанный под ленту терминал отдаёт фокус полю ввода |
| `src/renderer/components/NewSessionDialog.tsx` | Имя (проверка), папка с подсказками с ВМ, «Сразу запустить claude» |
| `src/renderer/components/Composer.tsx` | Поле ввода: подсказки `/` и `@`, картинки (Ctrl+V, перетаскивание, 📎), модель и effort, отправка; карточка меню над полем (поле неактивно), «Остановить · Esc» |
| `src/renderer/components/HintPopup.tsx`, `ChoiceMenu.tsx`, `AttachmentChip.tsx` | Список подсказок, меню выбора, значок картинки с прогрессом |
| `src/renderer/terminal-theme.ts` | Палитра ANSI терминала для светлой и тёмной темы |
| `src/renderer/styles/app.css` | Стили компонентов |
| `src/renderer/` | Интерфейс на React; `styles/tokens.css` — цвета и шрифты обеих тем |
| `src/shared/ipc.ts` | Контракт `window.api`, `Result<T>`, коды ошибок |
| `src/shared/quote.ts` | `shellQuote`, `cdPrefix` (~ через $HOME), `validateSessionName` |
| `src/shared/tmux-parse.ts` | `TMUX_LS_FORMAT`, `parseSessions` |
| `src/shared/ping-parse.ts` | `parsePing`: успех по `TTL=`, любая локаль Windows и Linux |
| `src/shared/osc52.ts` | `parseOsc52`: текст из OSC 52, запрос чтения буфера (`?`) не выполняется, предел 4 МБ |
| `src/shared/paste.ts` | `bracketedPaste` (ESC вырезается), `slashCommand`, `keyBytes` (белый список клавиш карточки меню, только строки) |
| `src/shared/plural.ts` | `plural`: склонение после числа (1 сессия, 2 ядра, 21 ядро) |
| `src/shared/links.ts` | `externalUrl`: ссылка из ленты для браузера — только http(s) через `new URL`, без логина в адресе |
| `src/shared/hints.ts` | `detectTrigger`, `filterHints`, `BUILTIN_COMMANDS`, `parseInitialize` |
| `src/shared/known-hosts.ts` | Отпечаток SHA256, сверка с known_hosts (в т.ч. хешированные и с портом) |
| `src/shared/backoff.ts` | Паузы переподключения 1, 2, 5, 10, 30 с |
| `src/shared/layout.ts` | Раскладка сайдбара: `reconcile`, `move` (с прижатием к зоне закреплённых), `togglePin`, группы, `addNewToGroup` (новая сессия в группу до прихода в список tmux, группа разворачивается), `normalize`, `rowsOf`, `paginate` (страницы, «продолжение» группы) |
| `src/main/layout-store.ts` | `LayoutStore`: layout.json `{ адрес ВМ: раскладка }`, запись с задержкой 300 мс |
| `src/shared/claude-session.ts` | `projectSlug`, `transcriptPath` (только UUID), `pickClaudeSession` — сессия Claude Code по живому pid панели |
| `src/shared/transcript-parse.ts` | Журнал Claude Code → элементы ленты: сообщения, ответы, размышления, инструменты с результатами, действия субагентов внутри Task (по цепочке `parentUuid` от задания; ранняя часть журнала не меняет текущий Task), слеш-команды и `!` bash; неизвестное пропускается |
| `src/shared/metrics-parse.ts` | Разбор /proc/stat, meminfo, loadavg, uptime, net/dev, `df` (только локальные устройства), `ps`; имена tmux-сессий у процессов claude; форматирование «5,1 ГБ», «1,2 МБ/с», «12 д 4 ч» |
| `src/main/metrics.ts` | `MetricsService`: одна команда по SSH раз в 10 с в фоне и раз в 2 с при открытой панели; без подключения — замер с ошибкой («нет данных N с»); сведения о системе |
| `src/main/session-watch.ts` | `SessionWatcher`: раз в 500 мс — процесс панели, экран (`classifyScreen`), раз в 2 с — сессия Claude Code из `sessions/*.json`; события только при изменении |
| `src/main/transcript.ts` | `TranscriptService`: хвост журнала (1,5 МБ целыми строками), `tail -F` по SSH (умирает вместе с каналом), подгрузка ранней части |
| `src/shared/screen-parse.ts` | Разбор экрана Claude Code: `stripAnsi` (в т.ч. без серого текста), `inputText` (поле ввода), `parseMenu` (меню с номерами и без), `parseStatus` (спиннер), `classifyScreen`, `menuKeysFor` |
| `scripts/dev/fake-anthropic.mjs`, `scripts/dev/capture-screen.sh` | Фейковый Messages API и снимки экранов настоящего claude для фикстур — без запросов к модели |
| `.gitattributes` | Фикстуры с LF на любой ОС (на Windows CRLF ломал разбор в CI) |
| `scripts/check-no-host.mjs` | Защита адреса ВМ, вызывается из `.githooks/pre-commit` |
| `tests/unit`, `tests/integration`, `tests/e2e` | Тесты: Vitest и Playwright |
| `tests/fixtures/fake-claude.mjs` | Фейковый claude для тестов: поле ввода как у настоящего, теряет Enter во время обработки вставки, меню, «работает», пишет sessions/*.json и журнал |
| `tests/fixtures/metrics/*.txt` | Вывод /proc и df с ВМ, синтетические ps и sessions |
| `tests/fixtures/transcript.jsonl` | Синтетический журнал Claude Code в форме настоящего |
| `tests/fixtures/screens/*.ans` | Снимки экранов Claude Code 2.1.303 (`capture-pane -e`) |
