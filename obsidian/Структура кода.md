# Структура кода

Часть [[Claude VM GUI]].

| Путь | Назначение |
|---|---|
| `src/main/index.ts` | Окно, настройки безопасности (contextIsolation, sandbox, CSP), запрет навигации |
| `src/main/config.ts` | `loadConfig` (config.json → vm.config.json при разработке), `saveConfig` с проверкой |
| `src/main/preflight.ts` | `runPing` (системный ping, cp866 на Windows), `checkTcp`, `runPreflight` |
| `src/main/ssh.ts` | `SshConnection`: ключ или ssh-agent, проверка known_hosts, exec/PTY/SFTP, автопереподключение |
| `src/main/ipc.ts` | `IpcHub`: каналы «группа:метод», события «группа:событие», заглушки `NOT_CONNECTED` |
| `src/preload/index.ts` | Мост `window.api` через contextBridge, реализует `Api` |
| `src/renderer/api.ts` | Типизированный `api` для компонентов |
| `src/renderer/` | Интерфейс на React; `styles/tokens.css` — цвета и шрифты обеих тем |
| `src/shared/ipc.ts` | Контракт `window.api`, `Result<T>`, коды ошибок |
| `src/shared/quote.ts` | `shellQuote`, `cdPrefix` (~ через $HOME), `validateSessionName` |
| `src/shared/tmux-parse.ts` | `TMUX_LS_FORMAT`, `parseSessions` |
| `src/shared/ping-parse.ts` | `parsePing`: успех по `TTL=`, любая локаль Windows и Linux |
| `src/shared/paste.ts` | `bracketedPaste` (ESC вырезается), `slashCommand` |
| `src/shared/hints.ts` | `detectTrigger`, `filterHints`, `BUILTIN_COMMANDS`, `parseInitialize` |
| `src/shared/known-hosts.ts` | Отпечаток SHA256, сверка с known_hosts (в т.ч. хешированные и с портом) |
| `src/shared/backoff.ts` | Паузы переподключения 1, 2, 5, 10, 30 с |
| `scripts/check-no-host.mjs` | Защита адреса ВМ, вызывается из `.githooks/pre-commit` |
| `tests/unit`, `tests/integration`, `tests/e2e` | Тесты: Vitest и Playwright |
