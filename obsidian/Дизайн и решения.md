# Дизайн и решения

Часть [[Claude VM GUI]].

## Решения

- **Терминал, а не свой чат.** Внутри окна — настоящий `claude` в tmux (xterm.js), вокруг — оболочка claude.ai. Так работают все функции Claude Code, а сессию можно продолжить из cmd.
- **Буфер обмена через OSC 52.** Claude Code копирует выделение через `tmux load-buffer -w`, tmux передаёт текст терминалу последовательностью OSC 52; xterm.js сам её не обрабатывает, поэтому приложение кладёт текст в буфер Windows. Запросы чтения буфера с ВМ игнорируются.
- **Electron + React + TypeScript.** SSH через `ssh2`, терминал — xterm.js, сборка electron-vite и electron-builder.
- **Подсказки без запросов к модели.** Команды, скиллы и модели берутся из `claude -p … initialize` (служебный запрос stream-json) в рабочей папке сессии; файлы — `git ls-files`.
- **Картинки** загружаются по SFTP в `~/.cache/claude-vm-gui/uploads/`, в сообщение подставляется путь.
- **Пароль** (0.2) — необязателен; хранится в `config.json` зашифрованным через Electron `safeStorage` (DPAPI), в интерфейс не передаётся. Порядок входа: ключ → ssh-agent → пароль → keyboard-interactive.
- **Раскладка сессий** (0.2) — `layout.json` в папке данных приложения, отдельно для каждой ВМ; tmux не меняется. Закреплённые всегда выше незакреплённых в своём списке; закрепление действует внутри списка (верхний уровень или группа) и снимается при переезде в другой; группы не вкладываются.
- **Адрес ВМ** — только в `vm.config.json` (в `.gitignore`) и в настройках приложения; git-хук отклоняет коммит, если адрес попал в файлы.

## Внешний вид

Палитра бренда Anthropic (слоновая кость `#FAF9F5`, глина `#D97757`, тёплые серые), заголовки Source Serif 4, терминал JetBrains Mono, интерфейс Segoe UI. Светлая и тёмная темы. Макет — 5 экранов: главное окно, подключение, тёмная тема, новая сессия, модель и effort.

## Найдено при проверке с настоящим claude

- Если в терминале открыто меню Claude Code (запрос разрешения, «доверять папке?»), Enter из поля ввода выбрал бы пункт по умолчанию — например, разрешил бы инструмент. Поэтому перед отправкой текста, `/model` и `/effort` приложение смотрит последние строки терминала и при подсказке «Enter to confirm» / «Esc to cancel» блокирует отправку с просьбой ответить в терминале.
- `/model` в Claude Code сохраняет модель по умолчанию в `~/.claude/settings.json`.
- Картинка, вставленная путём, распознаётся Claude Code как `[Image #N]`.
- Отправка проверяет, что на переднем плане claude (`pane_current_command`), иначе текст выполнился бы в bash. Enter отправляется отдельно от вставки.
- Подсказки запрашиваются с `--setting-sources user --strict-mcp-config`: хуки и MCP чужого проекта не запускаются.
- Второй Enter (0.1.x): если Enter пришёл в одном куске с концом вставки (по сети пакеты склеиваются), Claude Code его теряет — картинка остаётся в поле как `[Image #1]…`. С 0.2 Enter отправляется, когда содержимое поля перестало меняться, затем проверяется, что поле очистилось; не очистилось — один повтор, потом ошибка «Claude Code не принял Enter».
- Если хост уже есть в known_hosts, разрешены только его типы ключей (как HostKeyAlgorithms в OpenSSH).
