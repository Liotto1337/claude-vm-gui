# Дизайн и решения

Часть [[Claude VM GUI]].

## Решения

- **Терминал, а не свой чат.** Внутри окна — настоящий `claude` в tmux (xterm.js), вокруг — оболочка claude.ai. Так работают все функции Claude Code, а сессию можно продолжить из cmd.
- **Electron + React + TypeScript.** SSH через `ssh2`, терминал — xterm.js, сборка electron-vite и electron-builder.
- **Подсказки без запросов к модели.** Команды, скиллы и модели берутся из `claude -p … initialize` (служебный запрос stream-json) в рабочей папке сессии; файлы — `git ls-files`.
- **Картинки** загружаются по SFTP в `~/.cache/claude-vm-gui/uploads/`, в сообщение подставляется путь.
- **Адрес ВМ** — только в `vm.config.json` (в `.gitignore`) и в настройках приложения; git-хук отклоняет коммит, если адрес попал в файлы.

## Внешний вид

Палитра бренда Anthropic (слоновая кость `#FAF9F5`, глина `#D97757`, тёплые серые), заголовки Source Serif 4, терминал JetBrains Mono, интерфейс Segoe UI. Светлая и тёмная темы. Макет — 5 экранов: главное окно, подключение, тёмная тема, новая сессия, модель и effort.
