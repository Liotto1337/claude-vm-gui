- Отвечать пользователю и писать комментарии — по-русски, плотность комментариев как в окружающем коде.
- В релиз — только после ревью этапа (A и B) и исправления замечаний Critical/Important.

## Уточнения к спецификации (решены при планировании)

- История меню хранится в `localStorage` рендерера (в Electron и WebView он постоянный), а не в `prefs` — так один код на обе платформы; при недоступном хранилище история живёт до перезапуска.
- Android `upload.read` читает через `transport.stream` (двоичный канал), а не `exec`: `exec` отдаёт строку и испортил бы двоичные данные.
- Android: опрос `SessionNotifier` остаётся одной командой по всем сессиям с claude, фильтр по `watched` — в Kotlin; при пустом списке опроса нет. Имена сессий не попадают в shell-команду — нет риска с кавычками.

## Review Focus

1. Вставка, где внутри текста есть строка, похожая на закрывающий тег (`</pasted_content id="x">` в середине) — разворачиваются только парные теги с одинаковым `id`, остальной текст не трогается.
2. Ошибка отправки, когда пользователь уже набрал новое — ни старый, ни новый текст не теряется, вложения не дублируются.
3. `upload.read` с путём вне папки загрузок (`…/uploads/../../.ssh/id_ed25519`, символьная ссылка) — отказ, ничего не читается.
4. Меню закрылось, пока приложение было свёрнуто/сессия не открыта — итог не придумывается из старого экрана другой сессии (якорь и экран — одной сессии).
5. Сессию переименовали/удалили — она выпадает из `watched`, и уведомление о ней не приходит; пустой `watched` — опроса нет вовсе.
